# Guide screenshots

Images 01–16 are actual browser captures of `swap-ui/hosted.html` and its JavaScript at commit `9288c43b`, served by a disposable local relay. They illustrate the same interface deployed at https://hegemon-swap-testnet.willdoyle422.workers.dev/.

The reference screenshots supplied in the chat informed the HGN connection and unlock instructions. Their original image bytes were not available to the execution workspace, so the images committed here are newly captured equivalents, not copies of those attachments. No companion readiness, wallet balances or on-chain success was simulated for these captures. The example ADA/ETH offer and reservation existed only in the disposable local database. No real wallet was connected and no blockchain transaction was sent.

The example share-link field and encrypted inbox-backup field in `11-save-and-share.png` were hidden using the browser screenshot tool's masking option. No real pairing token, wallet passphrase, signing key or production offer appears in these images.

Image numbering follows the guide. `03-choose-asset.png` shows the HGN asset choice; the remaining amount and review screens use the clearly labeled example of 5 ADA for 0.0001 ETH. The screenshots cover setup, offer creation, reservation and entry into swap recovery; transaction steps later in the guide are described from the source controls, not illustrated as successful public-chain transactions.

`17-companion-wallet.png` is a real Tk window capture from the companion GUI test added after the original guide. Its node status, balance, all-zero pairing token and address are disposable test fixtures. It illustrates the wallet card, read freshness, separate balances and copy confirmation; it is not a funding destination or evidence of a public-wallet balance.
