# Canonical compact FRI proof frontier

This directory preserves the cumulative standalone Pay1x2 prototype that produced the current verified proof-size frontier. Starting from the frozen all-private layout, the patch includes the direct precommit/mask co-commitment, canonical terminal-message serialization, canonical compact Merkle multiproofs, and verifier-known FRI value elision.

For each committed FRI leaf, the value at the queried offset is already the preceding round's authenticated claim. The prover omits that redundant scalar. The verifier derives the offset from the Fiat-Shamir query index, reinserts the prior claim, reconstructs and hashes the complete leaf, authenticates the unchanged Merkle root, repeats the existing claim-equality check, and performs the unchanged fold. Multiple queried offsets in one leaf and duplicate queries use a canonical sorted map; no prover-chosen position metadata is serialized.

The supervised full V5/Delta Pay1x2 run measured **244,240 proof bytes** and a **244,252-byte HGSP envelope**. This is 5,280 bytes (2.12%) below the immediately preceding 249,532-byte compact-multiproof envelope, 27,936 bytes (10.26%) below the terminal-message envelope, and 136,256 bytes (35.81%) below the original 380,508-byte full-relation envelope. The circuit remained 1,883,192 compiled rows with the exact 478-byte public statement and 40 SHAKE256 permutations.
