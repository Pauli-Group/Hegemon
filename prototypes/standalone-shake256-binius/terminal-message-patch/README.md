# Canonical terminal-message proof optimization

This cumulative source patch starts from the fixed all-private Binius baseline and includes the measured direct precommit/mask co-commitment before changing FRI terminal serialization. It commits the canonical inverse-NTT terminal message, sends that message instead of the redundant rate-expanded terminal codeword, and deterministically re-encodes the codeword in the verifier under the same Gao-Mateer domain before running the existing query and final-fold checks.

For the exact full Pay1x2 shape (`GF(2^128)`, 116 queries, one ZK oracle with log message length 21), the rate-three transcript model changes the FRI schedule from `[4,4,4,3]` with terminal dimension 6 to `[4,4,3]` with terminal dimension 10. Its predicted proof was 279,728 bytes. The real supervised rate sweep did better: the selected canonical proof is **272,176 bytes** and its exact HGSP envelope is **272,188 bytes**. This is 36,896 bytes (11.94%) below the previous verified 309,072-byte prototype proof and 78,624 bytes (22.41%) below the all-private 350,800-byte proof.
