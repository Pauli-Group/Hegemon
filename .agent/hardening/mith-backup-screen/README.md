# Fail-closed MiTH backup screen

Verdict: no MPC-in-the-head or VOLE-in-the-head candidate survives as Hegemon's compact all-W64 transaction proof backup.

The strongest generic interactive source theorem is QuickSilver's information-theoretic zero knowledge in an ideal extended-sVOLE hybrid. Its online correction vector alone is one Goldilocks element per multiplication constraint:

    20,457,227 * 1 * 8 = 163,657,816 bytes

The public large-odd-field VOLE-in-the-head paper reports, in Table 1, an average 128-bit profile of three field elements per multiplication gate for `p` near `2^64`. Applying that pinned source profile to the lower-bound Hegemon geometry gives exactly:

    20,457,227 * 3 * 8 = 490,973,448 bytes

That second number is an exact arithmetic projection, not a measured proof and not a universal theorem lower bound. It omits startup/commitment data, Fiat–Shamir framing, serialization, the statement, and the not-yet-compiled all-W64 manifest constraints. Both screens already exceed the 524,288-byte outer envelope by orders of magnitude.

The security gate independently fails. QuickSilver supplies an interactive hybrid theorem. VOLE-in-the-head upgrades it to public verification and gives a multi-instance classical programmable-ROM NIZK theorem with explicit query losses, but ePrint 2023/996 does not give a finite-QROM theorem. FAEST v2's later finite-QROM result is EUF-CMA for its exact AES/Rijndael signature relation; it is not a generic arbitrary-R1CS or complete-zero-knowledge theorem.

ZKBoo/Picnic-style direct generic MPC is even larger. Using the paper's exact formula, 219 repetitions for classical `2^-128` base soundness, 19,301,403 private field variables, 20,457,227 multiplication gates, one output, 64-bit canonical field elements, and a 128-bit tape seed yields an optimistic 139,314,250,032-byte view payload. The pinned ZKBoo theorem is only special honest-verifier zero knowledge and describes Fiat–Shamir as a heuristic; complete NIZK ZK and finite QROM are absent.

Aurora plus the CMS19 QROM compiler is retained only as an honest control: it does have a real QROM theorem path and bounded-query perfect IOP zero knowledge. It belongs to Hegemon's separate odd-field IOP/WHIR investigation. This package establishes neither its exact all-W64 relation, concrete transcript, composed security, nor proof bytes.
