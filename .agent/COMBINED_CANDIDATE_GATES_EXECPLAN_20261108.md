## Design decisions

The existing preparation filename is retained. --combined-candidate is explicit
source workflow generation; no environment or runtime selection can authorize a
candidate. --prepare may return PASS_PENDING_SOURCE_PREPARATION; final artifact
checks and ordinary binary audit remain closed until all real evidence exists.

Frozen source inventories cover every tracked/unignored path and independently
scan ignored Rust, Lean, Cargo, script and build-configuration inputs. Git
executable modes are bound too. They exclude this self-referential config and the distinct
candidate evidence namespace. The evidence namespace must contain data only and
is separately pinned; qualification executables must be source-inventoried under
scripts/. The fixed Git base authenticates beforeimages, with no source removals.
A user-reviewed allowlist must equal the entire observed delta before freezing.

The source review binds candidate source/delta and exact qualification command
inventory. Final proof verification uses authenticated unchanged predecessor
executors, preserving five actual proof cases and thirty rejection controls.
Each qualification argv must include the literal `{artifact_manifest}` token;
the checker substitutes its actual manifest path without a shell. Six reviewed
Python suite entrypoints must actually execute and return exact
source/artifact/target-bound gate receipts; retained or hand-written PASS JSON
cannot substitute for command execution. Physical ASIC qualification is false.

Formatting retains only byte-unchanged eec3bb14 predecessor debt. Changed files
must format cleanly unless the freeze records separately reviewed exact existing
debt migrations. New debt paths always reject. No predecessor baseline is edited.

## Validation and recovery

Only lightweight Python regression/mutation suites run in this worker. No Cargo,
node, Git push or dispatch. The checked-in config deliberately stays pending, and
final authorization is expected to reject. Root can inspect the exact diff, fill
source freeze/review/commands after actual evidence, and retain any failures.
