# Witness-free eager SMZ9 algebraic simulator

The implementation is
`formal/crypto/HegemonCrypto/SmallWoodV8Smz9EagerSimulator.lean`. It extends the
frozen `SmallWoodV8Smz9EagerPrivacy.lean` construction without changing that file
or any runtime behavior. This is an algebraic-output construction, not a
production authorization or a claim that Rust execution has been refined.

Important current boundary: `PublicPiopParameters.expressions` is the older
`ProductionConstraintExpression` arithmetic interface. The live relation uses
8,271 `FieldExpression` instructions, including inverses and selectors. The
current `source_instantiated_eager_algebraic_output_law` instantiates the older
interface; it does **not** establish equivalence to that live adapter. The new
`ProgramPolynomials` bridge and a subsequent constructor/law specialization are
required before crediting a current-program eager simulator.

## Actual simulator inputs and outputs

`eagerPublicAlgebraicFields` takes only public statement/program data, batching
coefficients, the full previously sampled responses `D,T`, opening points and
DECS targets, and the fresh 7,156-coordinate opening view. Its inputs contain
no witness values, witness polynomials, original masks, or retained secret
leaf inputs. Public mask openings are calculated by `publicMaskOpenings` from
the generated arithmetic program and public CSR weights; there is no supplied
mask-opening callback.

The output has the exact source algebraic matrix dimensions:

| Field | Dimensions | Construction |
| --- | --- | --- |
| Row scalars | 6 × 696 | 686 witness openings followed by five nonlinear and five linear mask openings |
| Partial evaluations | 6 × 40 | 35 nonlinear columns followed by five linear columns |
| Combination tails | 12 × 20 | The same early LVCS coordinate |
| Subset evaluations | 20 × 128 | The same later LVCS coordinate |
| DECS mask evaluations | 20 × 5 | `D(target) − gammaD * reconstructedRows(target)` |
| DECS highs | 5 × 368 | Coefficients 20 through 387 of that same `D` |
| Nonlinear highs | 5 × 483 | Coefficients 6 through 488 of that same nonlinear `T` |
| Linear highs | 5 × 126 | Coefficients 7 through 132 of that same linear `T` |

In the nonconstant-only linear vector, source coefficient 7 has vector index
6. No high coefficient is sampled again, and no full response is replaced by
an independent pair of high coefficients and mask evaluations.

The Merkle root/tree, authentication paths, salt, opened tapes, final PIOP
digest and canonical byte encoding are retained/generated by the separate
oracle-game layer. This module does not call the existing compact simulator
or assert that its coin distribution agrees with the eager construction.

## Reconstruction and checked round trips

The PCS reconstruction is literal source algebra. A nonlinear first column
is recovered using weights `r^64,r^128,r^192,r^256,r^320,r^384,r^419`; a linear
first column uses `r^63`. The complete 736-column layout is
`686 + 5*8 + 5*2`, and each opening's vector splits into consecutive halves
of 368. Checked round trips cover every column/index, not selected examples.

For each DECS target, the public combination heads and early tails are
concatenated in rotated interpolation order: 20 tail nodes, then 368 head
nodes. Their 388-node interpolations equal the source matrix combinations
of all 140 opened rows. Combining those twelve values with the 128 serialized
subset values gives a bijection on the full 140-row vector, using the actual
selected-block injectivity predicate. Its inverse is exactly the unique
linear solution used by the source matrix inversion. The checked round trip
recovers all original row evaluations.

The unmasked DECS combination polynomial is reconstructed from all 388
coefficients; its degree bound follows from the Lagrange basis. This proves
that subtracting `gammaD * rows` from the same `D(target)` recovers the
original mask-polynomial evaluation. This step does not demand an independent
mask-evaluation law.

Source anchors in `circuits/transaction/src/smallwood_engine.rs` are
`pcs_build_opened_evaluations` and `pcs_reconstruct_combi_heads` at
10401–10504, `lvcs_recompute_rows` at 10937–10991, and PCS proof serialization
at 2867–2919. Physical serialization orders combination tails, subset,
partials, authentication paths/tapes, masking evaluations, then DECS highs;
the named Lean structure is not itself a byte encoder.

## Source-instantiated law, not a probability premise

`public_mask_openings_match_source_masks` instantiates the PIOP recovery
theorems with the source coefficient vectors and generated arithmetic program.
It proves both mask-opening families from valid packing constraints, public
linear target validity, source degree bounds and admissible opening points.
These are arithmetic correctness premises, not an assumed simulation law.

Within that older arithmetic-expression interface, the source-side functions
are explicit:

```text
sourceRecoveredPiopMasks:          Q = T − F(W)
sourcePcsBaseForTranscript:        evaluate the actual unrandomized Q chunks
sourcePcsColumnPolynomialsForTranscript:
                                  W columns + next-column-randomized Q columns
sourceCommittedHeadsForTranscript: exact 70-by-736 / 140-by-368 reshape
```

The source response is proved to be exactly `F(W)+Q` in its 3,105 published
coefficient coordinates, including the derived linear constant convention.
Consequently its explicit inverse reproduces the same full `T`. Neither
the PIOP offset nor the PCS base/head constructor depends on the later LVCS
tail coins. This is essential when composing the two chronological laws.

`source_instantiated_eager_algebraic_output_law` substitutes those interface-specific
functions into the previously derived dependent witness/PCS/LVCS transport.
The honest side retains the explicit source chronological opening computation;
the simulator side samples a uniform 7,156-coordinate view and applies the
witness-free constructor. The optional DECS selector failure is preserved
through the output projection; the proof never conditions on success.

Uniform `D,T` and their retained original masks come from the earlier
`chronological_joint_mask_transport`, not from a supplied honest/simulated
equality. The separate quantum-game modules account for independent leaf
outputs, final-input reprogramming and hidden unopened programs.
