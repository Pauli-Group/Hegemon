# Hegemon v0.11.4: combined pre-mainnet upgrade at H18,660

**Upgrade before block 18,660.** This coordinated pre-mainnet release activates
one-hour ASERT difficulty, 24-bit mining version rolling and 60-block treasury
payout batches together. It also repairs fresh block timestamp admission and
temporarily future-dated mining-work retries after clock correction.

The selected height is **18,660**. Friday morning November 13, 2026 in Calgary
is a production-pace estimate; block height controls the upgrade. Both reference
nodes will be upgraded in order: hegemon-dev, then hegemon-ovh, after final checks.
Final publication and deployment results are recorded in release receipts.

The network remains `v0.11`, with existing genesis, chain ID, network manifest,
wallet pins, PrivateSpend proof relation, transaction format and encrypted notes.
The product version is `0.11.4`. Internal Cargo versions and exact Cargo.lock stay
unchanged because the lockfile participates in the proof relation digest.

At H18,660 native blocks use combined rules fingerprint
`ec304529f49e7ddc777e0ca78b189acec753d4fb18aafe15761e686ea3596b7f`.
Legacy rules apply below that height. ASERT retains the 60-second target interval
with one-hour half-life, anchored to H18,659's target/height and H18,658's timestamp
on the candidate parent's own branch. Mining version rolling accepts only the
negotiated source-owned mask. Software tests establish no physical ASIC model
or firmware performance.

Treasury entitlements accrue every active block and are paid in batches of 60.
The first batch is H18,660..H18,719, with payout at H18,719 and first possible
spend at H18,839 under the unchanged 120-block maturity. Miner rewards and fees
remain per block. Accounting distinguishes pending scheduled entitlement from
actually issued notes, including omitted miner rewards.

Install the qualified v0.11.4 artifact before H18,660, preserve chain/wallet
backups, verify checksums and keep the shared seeds:

    HEGEMON_SEEDS="hegemon.pauli.group:30333,devnet.hegemonprotocol.com:30333"

All miners must share those seeds to avoid partitions and forks. Keep NTP or
chrony enabled: future-skewed PoW timestamps reject. Preserve operator RPC
settings; this upgrade enables no external public endpoint. Existing wallet
submission policy and client key/proving ownership remain unchanged.

Before activation rollback requires verified current-chain height and retained
state. At/after H18,660 v0.11.3 cannot validate new rules and must not be restarted
as an ordinary rollback. Follow the
[combined activation runbook](../../runbooks/combined_upgrade_activation.md).

Qualification requires exact scheduled source, production H−1/H/H+1 tests,
separately attributed funded H120 Development rehearsal, formal/source checks,
all required CI, and actual final proof/H0 plus six fresh affected suites on all
four platforms. Earlier unset-height evidence retains its attribution. Technical
qualification grants no new cryptographic production, mainnet or physical ASIC
authority. Fresh mainnet requires its own genesis/ASERT bootstrap and qualification.
