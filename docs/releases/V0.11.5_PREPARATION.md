# v0.11.5 source preparation

This PR adds bounded Bitcoin80 time rolling on the existing pre-mainnet chain,
scheduled at H28,860. It stacks on
`codex/sync-recovery-current-network-20261110` at
`ad77c8d564944972b6ae5e7cab26fcf500972aff`, preserving v0.11.4 and subsequent
sync fixes. The product label is 0.11.5; internal Cargo package versions and
the exact proof-bound Cargo.lock remain unchanged.

The [consensus specification](../consensus/NTIME_ROLLING.md) defines header
commitment, range semantics, RPC fields and the Friday November 20 Calgary
morning estimate. H28,860 governs activation; no wall-clock trigger is used.
The original H18,660 ASERT anchor and treasury cadence remain active.

This document records source preparation, not accepted release artifacts.
`config/testnet/0.11/release.json`, v0.11.4 artifact pins, historic packagers and
qualification receipts continue to describe the published predecessor. They
must not be relabeled as v0.11.5 evidence. Publication requires an additive
v0.11.5 packaging profile bound to the new source and ordinary release binaries,
the required platform/proof and lifecycle qualification, independent review,
and the applicable release authorization. Operators and miners should receive
the announcement once that release is ready, with enough time to update before
H28,860. This PR does not publish, deploy or send that announcement.
