An expired offer cannot be newly reserved. Existing on-chain deadlines are separate.

What is an inbox key? When you create an offer, your browser creates a private inbox key. The preview uses it to set up encrypted messaging when someone reserves your offer. The swap itself does not require a conversation.

Why save a backup? It lets you restore the key if it is lost. You must choose to make the backup now; save the encrypted copy and its passphrase after creating the offer.

What the backup cannot restore: Your offer-owner credential, wallet, or swap secret. The owner credential is saved only in this browser. Without it, you cannot read the offer's messages as its maker or close the offer, even if you have this backup.

Guided swap
Paste the swap terms and the status printed by swap_engine_cli.py status. The page reads the chains through the hosted service, checks every escrow against the terms in your browser, applies the same timelock policy and the same decision rules as the engine, and tells you what comes next.       How do I start the local companion?
      On the computer running your Hegemon node, open a terminal in a checkout of this swap branch. The node must already be using HEGEMON_SEEDS="hegemon.pauli.group:30333,devnet.hegemonprotocol.com:30333" unless that list was deliberately rotated, and the computer must have NTP or chrony enabled. Every miner on the same network must use the same seeds. A future-skewed clock is rejected.
      For a node-status check only:
      umask 077
mkdir -p "$HOME/.local/share/hegemon-swap"
python3 scripts/local_swap_companion.py --hosted-node-status \
  --hegemon-rpc http://127.0.0.1:9944 \
  --token-file "$HOME/.local/share/hegemon-swap/companion-token"
