Connect local companion

Start the local companion and enter its pairing token from the private token file. The companion is read-only by default; optional Development actions require terminal approval. This token is not a wallet password and stays in this page's memory.

Experimental local Ethereum deployment

Deploy a single escrow to non-forked local Anvil using your connected wallet. This is a manual test action, not a complete swap; independently check the other leg and back up your secret first. Native ETH is locked at deployment. Token escrows need separate approval and funding transactions after deployment.

Recipient and conditions
Lock preparation creates an encrypted refund handoff in the companion's configured private directory. Back it up and protect its separate passphrase. Preparing and submitting are separate approvals. Closing this page does not necessarily cancel an action; check wallet status before retrying.


Local swap secret backups
Create a random secret and its public hashlock. The encrypted copy stays in this browser. Export it and keep the backup and its separate passphrase safe before using the hashlock; clearing browser storage deletes the local copy. This stores the secret only, not your wallet or the rest of the swap terms. A separately configured local Hegemon companion can unlock an exported backup for a manual test claim. This does not execute a complete swap.
