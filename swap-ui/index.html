Local action journal
The board saves public terms before requesting each local wallet action and records the result if one returns. Pending or uncertain entries may have been submitted: check the wallet or chain before retrying. These records reveal addresses and amounts, so store exports privately. They do not contain wallet keys, preimages, passphrases or complete swap recovery material.


Local swap secret backups
Create a random secret and its public hashlock. The encrypted copy stays in this browser. Export it and keep the backup and its separate passphrase safe before using the hashlock; clearing browser storage deletes the local copy.
